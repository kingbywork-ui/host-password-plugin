# 批量修改主机密码

手动选择已托管的 Linux/Unix SSH 登录账户，生成并修改密码。插件没有定时任务，也不会自动发送结果。每次执行前由 issh 主窗口展示账户和 SSH 路径，确认后验证 Vault 主口令；密码和主口令不发送到插件面板。

1. 在保险库设置中启用主口令，为目标账户保存当前登录密码。
2. 打开插件，解锁 Vault，选择账户并设置密码规则。
3. 点击“修改选中账户”，核对宿主显示的账户、跳板机及可能执行的 ProxyCommand，确认并输入 Vault 主口令。
4. 查看每个账户的结果。停止操作只阻止后续账户，正在处理的账户会继续安全收尾。

只有新密码经独立 SSH 密码认证成功并写入 Vault，状态才为“修改成功”。如果服务器禁用密码认证、连接中断或写入失败，状态可能为“待确认”；选择该账户并点击“处理待确认”，按界面提示验证。清除候选密码前应确认服务器上的上一次改密进程已经停止。

每账户在 Vault 中保存最近三次成功修改的密码及时间。可选择账户查看记录，或手动导出 JSON；默认导出不包含密码，勾选“导出密码”需要再次确认并验证主口令，生成的文件包含明文密码。

密码由系统安全随机数生成；默认每个账户使用独立密码。相同密码和三位批次前缀是可选项；前缀额外增加三位。当前通过 C 语言环境下的常见 `passwd` 提示交互，不识别的 PAM 提示会停止或保留待确认状态。目标必须已有可用的当前密码；登录方式可以使用现有 SSH 档案，改密成功仍需服务器允许 SSH 密码认证才能自动验证。

版本 `0.1.2` 要求 issh 宿主 `0.1.8` 或更高版本，插件以独立弹窗打开，并复用现有主机分组；未解锁 Vault 时不能配置或执行改密。

开发构建：本仓库是插件的独立源码仓库，执行 `npm install`，再执行 `npm run build`（产物在 `dist/`）与 `npm run package`（生成 `issh-plugin-host-password-<version>.tgz` 及同名 `.sha256`）。应用宿主和 `isshd` 需要包含对应的 `hostPassword.rotate` 网关与改密 RPC；仅安装插件包到旧版应用无法启用该功能。向正式商城发布需要使用项目既有的发布者签名和发布流程。
